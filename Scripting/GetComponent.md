Example: Car Delivery Game:
```
GetComponent<ParticleSystem>().Play();
```
وقتی ماشین یک بسته را برمی‌دارد، بازی یک افکت ذرات (Particle Effect) اجرا می‌کند تا بازیکن متوجه برداشتن بسته شود.
--------------------------------------
GetComponent<>(): Used to access a specific Component attached to the same GameObject.
GetComponent<>(): برای دسترسی به یک کامپوننت مشخص که روی همان گیم‌آبجکت قرار دارد، استفاده می‌شود.
