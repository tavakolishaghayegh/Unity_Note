# bool – A data type that stores only two values: true or false. Used to check conditions or track states
```
bool
```
—-
```
bool=false
bool=true
```
نوع داده‌ای است که فقط دو مقدار می‌تواند داشته باشد.
  (زمانی استفاده می‌کنیم که بخواهیم وضعیت یک چیز را مشخص کنیم؛ یعنی بدانیم چیزی فعال است یا غیرفعال، انجام شده یا نشده)
