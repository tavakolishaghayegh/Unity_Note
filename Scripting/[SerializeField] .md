
# [SerializeField] GameObject – Allows a GameObject to be assigned in the Unity Inspector.
```
[SerializeField] GameObject gameobject;
```
وقتی سریازفیلد گیم ابجکت میزاریم یعنی :تعریف یک متغیر برای دریافت و نگهداری و یعنی  یه نوع متغیر از نوع ابجکت تعریف کردیم که میتونیم از طریق برنامه یونیتی بهش یه ابجکت اضافه کنیم
مثال :این کار به‌تنهایی دو آبجکت را از نظر فیزیکی به هم متصل نمی‌کند؛ بلکه امکان دسترسی اسکریپت به آن آبجکت را فراهم می‌کند
